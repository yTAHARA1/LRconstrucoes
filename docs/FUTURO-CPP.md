# Possível uso futuro de C++

O site institucional da LR Serviços e Manutenção **não depende de C++**. Incluir C++ no funcionamento atual aumentaria a complexidade sem trazer benefício para um site institucional.

C++ poderia ser considerado futuramente em soluções específicas, como:

- processamento local de imagens de inspeção predial;
- integração com sensores ou equipamentos de monitoramento;
- análise de dados de dispositivos embarcados;
- ferramentas de alto desempenho para aplicações técnicas;
- componentes internos que precisem trabalhar sem conexão contínua.

Essas soluções devem permanecer separadas do site público e contar com documentação, testes e análise de segurança próprios.
